---
title: Žodynėlis
description: Ką reiškia žodžiai, kurie kartojasi portale ir kasoje.
icon: BookA
---

| Žodis | Ką reiškia |
| --- | --- |
| Akcija | Reklaminis baneris programėlės pradžioje arba prekės akcijos kaina. |
| Auditorija | Išsaugotas filtras, kam siųsti laiškus. |
| Darbuotojo kodas | Kodas, kuriuo darbuotojas prisijungia prie kasos pirmą kartą. |
| Filialas | Viena parduotuvė ar prekybos vieta. |
| Kasos nuolaida | Nuolaida, kurią kasininkas pritaiko mygtuku. |
| Kuponas | Dovana ar nuolaida, kurią klientas panaudoja vieną kartą. |
| Lygis | Kliento pakopa. Aukštesnė – daugiau naudų. |
| Lojalumo kortelė | Taisyklės, kiek taškų klientas gauna, ir kortelė jo programėlėje. |
| Nuorodos numeris | Pirkimo numeris, pagal kurį jį rasite. |
| PIN | 4 skaitmenys greitam prisijungimui kasoje. |
| Pirkimo dalis | Už ką suma: prekės, paslaugos, dovanų kuponas. Kiekviena turi savo taisykles. |
| Push | Pranešimas telefone iš programėlės. |
| Slenkstis | Nuo kokios reikšmės pasiekiamas lygis. |
| Sutikimas | Kliento leidimas siųsti jam reklamą. |
| Šablonas | Paruoštas tekstas ar dizainas. |
| Taškai | Ką klientas kaupia pirkdamas ir gali išleisti. |
| Transakcija | Vienas pirkimas arba grąžinimas. |
| Trigeris | Sąlyga, kada automatiškai siunčiama žinutė. |
