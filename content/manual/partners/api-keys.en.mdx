An API key lets another program, such as an online shop, work with your loyalty programme. A developer needs it.

Open <Path>API Credentials → All Credentials</Path>.

<Shot id="api-raktai" />

## Create a key

<Steps>
<Step>

Press <Ui>New API key</Ui>, type what it is for and choose the environment.

<Shot id="api-raktas-naujas" />

</Step>
<Step>

Copy the key and the secret. The secret is shown only once.

</Step>
<Step>

Give them to the developer safely, not by email.

</Step>
</Steps>

<Callout type="error" title="Deleting a key stops the integration">
All programs using it stop working at once.
</Callout>

For developers: [API documentation](/docs).
