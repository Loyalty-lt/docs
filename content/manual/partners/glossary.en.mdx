---
title: Glossary
description: What the words that keep coming up in the portal and the till mean.
icon: BookA
---

| Word | What it means |
| --- | --- |
| Audience | A saved filter of who to send emails to. |
| Consent | The customer's permission to send them promotions. |
| Coupon | A gift or a discount the customer uses once. |
| Location | One shop or point of sale. |
| Loyalty card | The rules of how many points a customer gets, and the card in their app. |
| PIN | 4 digits for a quick sign-in at the till. |
| Points | What the customer collects when buying and can spend. |
| Promotion | A banner at the start of the app, or a product's promotional price. |
| Purchase part | What the amount is for: goods, services, a gift voucher. Each has its own rules. |
| Push | A notification on the phone from the app. |
| Reference number | The purchase number you can find it by. |
| Staff code | The code a staff member signs in to the till with the first time. |
| Template | A ready text or design. |
| Threshold | The value at which a tier is reached. |
| Tier | The customer's level. A higher one – more benefits. |
| Till discount | A discount the cashier applies with a button. |
| Transaction | One purchase or refund. |
| Trigger | The condition when a message is sent automatically. |
