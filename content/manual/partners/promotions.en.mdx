A promotion is a banner at the start of the Loyalty.lt app. All app users see it, so Loyalty.lt reviews it before showing it.

Open <Path>Promotions</Path>.

<Shot id="akcijos-sarasas" />

## Submit a promotion

<Steps>
<Step>

Press <Ui>Submit a promotion</Ui>, type the title and add a picture.

<Shot id="akcijos-nauja" />

</Step>
<Step>

Enter the link the customer opens with a tap. It must start with `https://`.

</Step>
<Step>

If needed, set from when until when to show it. Press <Ui>Submit for approval</Ui>.

</Step>
</Steps>

<Callout title="A change needs approval again">
A changed promotion is not shown in the app until we approve it again.
</Callout>

## If something goes wrong

| What you see | What to do |
| --- | --- |
| “Image is too large – up to 2 MB” | Make the picture smaller. JPG and PNG work. |
| “The link must start with https://” | Paste the full web address. |
| Status <Ui>Rejected</Ui> | Open the promotion – the reason is at the top. Fix it and submit again. |
