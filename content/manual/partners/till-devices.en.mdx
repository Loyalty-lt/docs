A device appears by itself when a staff member signs in on it. The same code shows in the till's corner.

Open <Path>Till devices</Path>.

<Shot id="kasos-irenginiai" />

- **Name** – so you know which device it is, such as “Front desk”.
- **Shop** – where the device stands.
- **Can sign in with a PIN** – who already signed in on this device with a code and has a PIN. The cross removes a person from this device.

## A device is lost or sold

<Steps>
<Step>

Find it by its code and press <Ui>Delete</Ui>.

</Step>
<Step>

Everyone who used it will have to sign in with their staff code next time.

</Step>
</Steps>

If a staff code was lost too, generate a new card: [Staff](/partners/staff).
