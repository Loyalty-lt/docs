## Sukurti taisyklę

Spauskite <Ui>Sukurti taisyklę</Ui>, pasirinkite, kada siųsti, ir parašykite laišką.

| Kada | Ką reiškia |
| --- | --- |
| Praėjus N dienų po prisijungimo prie programos | Pasveikinimas naujam klientui. 0 – tą pačią dieną. |
| Gimtadienis | Laiškas per gimtadienį. |
| Nepirko N dienų (anksčiau pirkęs) | Primena apie jus. |
| Taškai baigia galioti per N dienų | Ragina taškus panaudoti. |
| Prisijungimo prie programos metinės | Padėka už ištikimybę. |

Laiškai siunčiami tik 08:00–20:00 Lietuvos laiku.

<Callout type="warn" title="Paleisti dabar">
Paleidus taisyklę ranka, laiškus iš karto gaus visi, kurie šiuo metu atitinka sąlygą. Pirma peržiūrėkite, kas jie.
</Callout>
