The customer plays in the Loyalty.lt app; the cashier adds stamps. A winner gets a coupon or points.

Open <Path>Games → All Games</Path>.

<Shot id="zaidimai-sarasas" />

## Create a game

<Steps>
<Step>

Press <Ui>Add game</Ui> and choose the type. All types open under <Ui>Show all game types</Ui>.

<Shot id="zaidimai-naujas" />

</Step>
<Step>

Type the name, description and prize, upload the pictures.

</Step>
<Step>

Set up the coupons: how many days they are valid and whether a customer can have several.

<Shot id="zaidimai-kuponai" />

</Step>
<Step>

Press <Ui>Create game</Ui>. Then set the prizes and rules.

</Step>
</Steps>

<Callout title="Until the prizes are set">
A new game has no prizes yet. Set them first, then turn the game on.
</Callout>

## Set the prizes

On the game's page press the type's settings, for example the stamps settings. On the right you see how the game looks on a phone.

<Shot id="zaidimai-antspaudai" />

| Type | What you set |
| --- | --- |
| Stamp card | How many stamps are needed and what the customer gets. |
| Wheel of fortune | The wheel's segments, their prizes and chances. |
| Scratch and win | The tickets, prizes and cover colour. |
| Quiz | Questions, answers and time. |

## Rules

| Field | What it means |
| --- | --- |
| Cooldown (min) | How often one can play. 1440 – once a day. |
| Max plays per day | The limit for one customer per day. |
| Max plays in total | The limit for one customer over all time. |
| Play cost (points) | How many points one play costs. 0 – free. |
| Require a purchase | A purchase is needed first. |

## Remind about the game

On the game's page, in the <Ui>Notification automations</Ui> block, create a push or SMS reminder. <Ui>Our recommendations</Ui> suggests ready-made ones.

<Shot id="zaidimai-vienas" />

## Results

Press <Ui>View detailed statistics</Ui>. You see how many times it was played, who played most and which prizes were given.

## Turn off and delete

<Ui>Deactivate</Ui> hides the game, but the results stay. Coupons already won stay valid.

<Callout type="error" title="Cannot be undone">
A deleted game cannot be restored. If it has only ended, deactivate it.
</Callout>

## If something goes wrong

| What you see | What to do |
| --- | --- |
| The customer does not see the game | Check that the game is active and the dates and shop fit. |
| No game at the till | At the till, choose the customer first. The game must be assigned to that shop. |
