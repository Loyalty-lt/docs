Ready plugins exist for WooCommerce, PrestaShop, Shopify and OpenCart. Plugins for Magento and Joomla! VirtueMart are being prepared.

## Hosted platforms

Eshoprent, Verskis, Shopsera and similar platforms do not let shops install their own modules. Only the platform itself can switch an integration on there.

Write to your platform's support that you want the Loyalty.lt loyalty program. The more shops ask, the sooner a platform adds it.

## What you can do right now

| Way | Who it suits |
| --- | --- |
| The till app | You give and accept points in a physical shop. See [Till](/till). |
| Product import from XML | Your products are shown in the Loyalty.lt app. See [Products](/partners/products). |
| The API | A developer connects any shop. See the [API documentation](/docs). |

<Callout title="Do you have a developer?">
Everything the plugins do can be done through the API. Give the developer the [API documentation](/docs) and an API key.
</Callout>
