Paruošti papildiniai yra WooCommerce, PrestaShop ir Shopify. OpenCart, Magento ir Joomla! VirtueMart papildinius ruošiame.

## Nuomojamos platformos

Eshoprent, Verskis, Shopsera ir panašios platformos neleidžia diegti savo modulių. Integraciją ten gali įjungti tik pati platforma.

Parašykite savo platformos pagalbai, kad norite Loyalty.lt lojalumo programos. Kuo daugiau parduotuvių paprašo, tuo greičiau platforma ją įdiegia.

## Ką galite daryti jau dabar

| Būdas | Kam tinka |
| --- | --- |
| Kasos programėlė | Taškus skiriate ir priimate fizinėje parduotuvėje. Žr. [Kasa](/till). |
| Prekių importas iš XML | Jūsų prekės rodomos Loyalty.lt programėlėje. Žr. [Prekės](/partners/products). |
| API | Programuotojas sujungia bet kurią parduotuvę. Žr. [API dokumentaciją](/docs). |

<Callout title="Turite programuotoją?">
Per API galima padaryti viską, ką daro papildiniai. Programuotojui duokite [API dokumentaciją](/docs) ir API raktą.
</Callout>
