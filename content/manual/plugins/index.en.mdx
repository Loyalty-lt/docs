A plugin connects your online shop to Loyalty.lt. Customers earn and spend points when they buy online, the same as at the till.

Points, tiers, coupons and stamp cards are managed in the partner portal. The plugin only shows and applies them in the shop.

## What a plugin does

| What | How it works |
| --- | --- |
| Sign-in | The customer scans a QR code with the Loyalty.lt app and the shop recognises them. |
| Earning points | Points are awarded when an order reaches the status you chose. |
| Spending points | The customer chooses how many points to use in the cart or at checkout. |
| Coupons | The customer sees their app coupons and can enter a code. |
| Tier discount | The discount of the customer's tier is applied to the cart by itself. |
| Stamps | Every paid order adds a stamp. |
| Cancelling and refunds | Awarded points are taken back, spent points return to the customer. |
| Product export | The shop's products are shown in the Loyalty.lt app. |

## What you need before you start

<Steps>
<Step>

You need a shop and a loyalty card in the partner portal. See [Shops](/partners/shops) and [Loyalty cards](/partners/loyalty-cards).

</Step>
<Step>

Create an API key. See [API keys](/partners/api-keys).

</Step>
<Step>

Download the plugin from the [Loyalty.lt website](https://loyalty.lt/en/business#integrations).

</Step>
</Steps>

<Callout title="Try it safely">
Choose the test environment when you create the API key. You can then try the plugin without touching real customers' points.
</Callout>
