API raktas leidžia kitai programai, pavyzdžiui, el. parduotuvei, dirbti su jūsų lojalumo programa. Jo reikia programuotojui.

Atidarykite <Path>API raktai → Visi raktai</Path>.

<Shot id="api-raktai" />

## Sukurti raktą

<Steps>
<Step>

Spauskite <Ui>Naujas API raktas</Ui>, įrašykite, kam jis skirtas, ir pasirinkite aplinką.

<Shot id="api-raktas-naujas" />

</Step>
<Step>

Nukopijuokite raktą ir slaptą kodą. Slaptas kodas rodomas tik vieną kartą.

</Step>
<Step>

Perduokite juos programuotojui saugiai, ne el. paštu.

</Step>
</Steps>

<Callout type="error" title="Ištrynus raktą jungtis sustoja">
Visos programos, kurios jį naudoja, nustoja veikti iš karto.
</Callout>

Programuotojui: [API dokumentacija](/docs).
