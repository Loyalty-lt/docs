# Loyalty.lt for developers

Loyalty.lt runs loyalty programmes for shops: customers collect points on purchases,
hold a digital card in the mobile app, and spend points or coupons at the till. This
documentation covers the **Shop API** — what you call from your e-commerce backend or
POS — and the official SDKs that wrap it.

## Get started in four steps

<Steps>
  <Step title="Get API credentials">
    Sign in to the [Partners Portal](https://partners.loyalty.lt) → **API Credentials**
    and create a **staging** pair. You get an API key (`lty_...`) and a secret, shown
    once — see [Staging](/docs/api-reference/staging).
  </Step>
  <Step title="Install an SDK">
    `npm install @loyaltylt/sdk`, `composer require loyaltylt/sdk`, or
    `pip install loyaltylt-sdk`. Or call the REST API directly.
  </Step>
  <Step title="Award your first points">
    Send a purchase to `POST /{locale}/shop/transactions/create`. That single call
    identifies the customer, records the order and credits the points.
  </Step>
  <Step title="Switch to production">
    Create production credentials in the same place and change the base URL from
    `staging-api.loyalty.lt` to `api.loyalty.lt`.
  </Step>
</Steps>

## The one call most integrations need

```bash
curl -X POST "https://staging-api.loyalty.lt/lt/shop/transactions/create" \
  -H "X-API-Key: $LOYALTY_API_KEY" \
  -H "X-API-Secret: $LOYALTY_API_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "user_email": "customer@example.com",
    "order_id": "ORD-2024-001",
    "order_total": 25.50,
    "currency": "EUR",
    "shop_id": 1
  }'
```

Points are calculated from `order_total` using the partner's rules. Pass `points` to
set the amount yourself, or `type: "cancellation"` / `"refund"` with the same
`order_id` to reverse it later.

## What else the Shop API does

<CardGroup cols={2}>
  <Card title="Loyalty cards" icon="credit-card">
    Look up a card by number, phone or email and read its points balance.
  </Card>

  <Card title="Coupons" icon="ticket">
    Verify a code at the till, hold it during checkout, then redeem it.
  </Card>

  <Card title="Games" icon="stamp">
    Stamp cards and other loyalty games — add stamps, read progress, issue rewards.
  </Card>

  <Card title="QR identification" icon="qrcode">
    Show a QR code on screen; the customer scans it in the app to sign in or to
    identify their card at the POS.
  </Card>

  <Card title="Realtime" icon="bolt">
    Scans and live basket updates arrive over a WebSocket channel, not by polling.
  </Card>

  <Card title="Product feed" icon="arrow-down-to-line" href="/docs/xml-import">
    Import your catalogue from an XML feed and keep prices in step.
  </Card>
</CardGroup>
