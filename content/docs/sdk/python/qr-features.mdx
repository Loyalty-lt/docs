# QR Features

Two QR flows, both driven from your server:

- **QR login** — the customer scans to sign in, and you get their JWT.
- **QR card scan** — the customer scans at the till, and you get their loyalty card.

Sessions expire after 5 minutes. The Python SDK polls; realtime subscription helpers
are JavaScript-only.

## QR login

```python
import time

# 1. Open a session and render session['qr_code'] as a QR image
session = sdk.generate_qr_login(device_name='Till 3', shop_id=shop_id)

# 2. Poll until the customer confirms
deadline = time.time() + 300
while time.time() < deadline:
    status = sdk.poll_qr_login(session['session_id'])

    if status['status'] == 'authenticated':
        token, user = status['token'], status['user']
        break
    if status['status'] in ('expired', 'cancelled'):
        break
    time.sleep(1)
```

In a web app, poll from the browser against your own endpoint rather than blocking a
worker:

```python
# Django
def qr_status(request, session_id):
    return JsonResponse(sdk.poll_qr_login(session_id))
```

| Status | Meaning |
|--------|---------|
| `pending` | Waiting for the customer to scan |
| `scanned` | Scanned; waiting for confirmation in the app |
| `confirmed` | Confirmed; the token is being issued |
| `authenticated` | Done — `token` and `user` are present |
| `cancelled` | The customer declined |
| `expired` | Generate a new session |

## QR card scan

The POS flow: identify the card without asking for a phone number.

```python
session = sdk.generate_qr_card_session(device_name='Till 3', shop_id=shop_id)
# render session['qr_code']

status = sdk.poll_qr_card_status(session['session_id'])

if status['status'] == 'authenticated':
    card = status['card_data']
    # card['loyalty_card_id'], card['card_number'], card['points'], card['user']
```

## Realtime

To avoid polling, connect to Laravel Reverb (Pusher protocol) from the browser. Read
the connection details from the API rather than hardcoding a host:

```python
config = sdk.get_realtime_config()   # key, host, port, scheme
```

Then subscribe in the browser to `qr-login.{session_id}` or `qr-card.{session_id}` —
see [Authentication](/docs/api-reference/authentication#realtime-instead-of-polling).
