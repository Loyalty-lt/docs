# Loyalty.lt Documentation

Source for [docs.loyalty.lt](https://docs.loyalty.lt), built with [Docusaurus](https://docusaurus.io) 3.

## Development

```bash
npm install
npm start          # dev server on http://localhost:3000
npm run build      # production build into build/
npm run serve      # serve the production build locally
npm run typecheck  # tsc
```

## Layout

| Path | What it is |
|------|------------|
| `docs/` | All documentation pages. `routeBasePath` is `/`, so `docs/api-reference/authentication.mdx` serves at `/api-reference/authentication`. |
| `docs/api-explorer/` | **Generated** — do not edit. Built from the OpenAPI spec by `npm run gen-api`, gitignored. |
| `static/` | Served verbatim at the site root: `/images/...`, `/logo/...`, `/api-reference/openapi.json`. |
| `src/components/mintlify/` | Compatibility layer, see below. |
| `src/css/custom.css` | Design tokens, kept in sync with `partners.loyalty.lt/src/app/globals.css` and `expo/theme/palette.ts`. |
| `static/assets/` | Self-hosted Mona Sans / Hubot Sans, copied from partners.loyalty.lt. |
| `sidebars.ts` | Four sidebars: Guides, API Reference, SDKs, API Explorer. Autogenerated from the folder tree. |
| `deploy/` | nginx config and the deploy script. |

## The Mintlify compatibility layer

This site was ported from Mintlify. Rather than rewrite ~1900 component usages
across 94 files, the Mintlify components are reimplemented in
`src/components/mintlify/` and registered globally in `src/theme/MDXComponents.tsx`.

That means `.mdx` pages keep writing what they always did:

```mdx
<Card title="Quick start" icon="🚀" href="/sdk/overview">Get going in five minutes.</Card>

<ParamField body="shop_id" type="integer" required>
  Which shop the transaction belongs to.
</ParamField>

<Warning>Rate limits apply.</Warning>
```

Supported: `Note` `Info` `Tip` `Warning` `Check` `Card` `CardGroup` `Columns`
`Tabs` `Tab` `CodeGroup` `Accordion` `AccordionGroup` `Expandable` `Steps` `Step`
`ParamField` `ResponseField` `RequestExample` `ResponseExample` `Frame` `Update`
`Tooltip` `Icon` `Latex`.

Callouts and tabs delegate to the real Docusaurus theme components, so they
inherit dark mode and mobile behaviour. To add one, implement it in
`src/components/mintlify/index.tsx` and register it in `src/theme/MDXComponents.tsx`.

Two Mintlify behaviours did not survive, and the content was adjusted:

- `{placeholder}` in prose is a JS expression in MDX 3 and must be escaped as `\{placeholder\}`.
- Snippets are plain MDX imports. `docs/snippets/_snippet-intro.mdx` is prefixed
  with `_` so it stays a partial instead of becoming a page.

## API reference

There are two, on purpose:

- **`/api-reference/*`** — hand-written pages with the context, examples and
  caveats a spec cannot express. Edit these normally.
- **`/api-explorer/*`** — generated from `static/api-reference/openapi.json` by
  [`docusaurus-plugin-openapi-docs`](https://github.com/PaloAltoNetworks/docusaurus-openapi-docs),
  with a live "try it" console. Never edit; regenerate instead.

```bash
npm run gen-api    # normalize the spec, then regenerate docs/api-explorer/
npm run clean-api  # delete the generated pages
```

`npm run build` runs `gen-api` first, so a clean checkout builds without extra steps.

### Spec normalization

`scripts/normalize-openapi-ids.mjs` runs before generation and fixes two things
that come out of l5-swagger in `api.loyalty.lt`:

1. 41 of 284 operations have an MD5 hash as their `operationId`, which would
   become the page URL. They are rewritten to readable names derived from the
   method and path.
2. One tag is `Admin\System`, and the backslash is an invalid escape in the
   generated YAML frontmatter, which breaks the build. It becomes `Admin / System`.

Both are worth fixing upstream in the `@OA\...` annotations; until then the
script keeps the build green. It is idempotent.

## Deployment

Same shape as the other loyalty.lt front-ends: pm2 runs the app on a local port,
nginx reverse-proxies to it.

| Piece | Where |
|-------|-------|
| pm2 app `docs.loyalty.lt` | `ecosystem.config.cjs` — `docusaurus serve` on **:3098** |
| nginx vhost | `deploy/nginx.conf.example` |
| Deploy | `./deploy/deploy.sh` — pull, `npm ci`, build, `pm2 reload` |

```bash
cd /var/www/vhosts/loyalty.lt/docs.loyalty.lt
./deploy/deploy.sh
```

The build goes into `build.new/` first and is only swapped into `build/` once
`index.html` exists, so a failed build cannot leave pm2 serving a half-written
site. nginx serves `/assets/` and `/api-reference/openapi.json` straight off disk
and proxies everything else, keeping the fingerprinted bundles off the node
process.

First-time setup (vhost, certbot, `pm2 save`) is in the comments at the top of
`deploy/nginx.conf.example`.

## Design system

Tokens match `partners.loyalty.lt` and the Expo app rather than the old Mintlify
palette:

| Token | Light | Dark |
|-------|-------|------|
| Primary green | `#65A949` | `#7BBC63` |
| Link green (contrast-safe) | `#4D903F` | `#7BBC63` |
| Heading | `#19352D` | `#F2F5F3` |
| Surface | `#E8F3E1` | `#1E3225` |
| Background | `#FBFBF9` | `#0E1512` |
| Border | `#E9E9E4` | `#263230` |

Mona Sans for text, Hubot Sans for headings, IBM Plex Mono for code. Mona and
Hubot are self-hosted from `static/assets/`; IBM Plex Mono comes from Google
Fonts, the same way `api.loyalty.lt` loads it.

The neon accent (`#E6FD5A` / `#CFFF45`) is intentionally **not** defined — it was
retired product-wide and replaced by brand green.

When partners' `globals.css` changes, update `src/css/custom.css` to match.

## Known content gaps

`BROKEN-LINKS.md` lists 26 links to pages that were never written. They were dead
on the Mintlify site too — Docusaurus just reports them. The build passes
(`onBrokenLinks: 'warn'`), but each is a dead end for a reader.
